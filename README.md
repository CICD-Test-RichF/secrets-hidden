# secrets-hidden

Synthetic repository created by the **ghassess sandbox seeder**.
Scenario: Secrets the repository's own gitleaks settings hide (allowlisted tests/ path, inline gitleaks:allow), a base64-encoded secret and a plain secret in current code (GH-SEC-005 / GH-SEC-006).

Everything here is fake test data. Do not use as an example of good practice
unless the scenario says "hardened".
